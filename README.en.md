# komorebi-ec-sample (English summary)

Sample repository for a Japanese book series on AI coding agents. It models the rebuild of "こもれびストア",
the online shop of a fictional household-goods maker. All companies, people, products and data are fictional.

- `packages/domain`: money, consumption tax, points, noshi (gift labels), address rules
- `apps/web`, `apps/api`, `batch`: order screen pricing, confirmation mail, receipt, batch jobs
- `docs`: requirements, design document, glossary (Japanese)

Setup: `pnpm install`, then `pnpm test`. Licence: MIT.
