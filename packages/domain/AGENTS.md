# AGENTS.md（packages/domain）

このディレクトリは金額の業務ルールです。リポジトリ直下の AGENTS.md に加えて、次を守ってください。

- 関数は純粋関数にする（DB、画面、現在時刻に依存しない。日時は引数で受け取る）。
- 金額は円の整数で扱う。小数（0.1 など）の掛け算で税額を出さない。浮動小数点の誤差で1円ずれる。
- 税額の計算は `src/tax.ts` の `calcOrderTotals` と `taxIncluded` だけに置く。
- テスト名は日本語で、ケース番号を先頭に書く（例：`[TC-TAX-002] 包装1点：税込3,650円の消費税は331円`）。
- 期待値は `docs/test/` の表と要件定義書から取る。実装を動かして出た値を期待値にしない。

## Code Review Rules

### 消費税と端数処理
- 消費税額を計算してよいのは calcOrderTotals() だけ。
  ほかの関数で金額に Math.round / Math.floor / Math.ceil を
  使っていたら指摘する
- 税率 0.1 などの直書きは指摘する（TAX_RATES を使う）
- 明細ごとに税額を持たせる変更は指摘する
  （税額は注文ごと・税率ごとに1回だけ計算する）
