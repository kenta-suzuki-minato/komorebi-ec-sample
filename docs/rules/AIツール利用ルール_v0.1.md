# AIツール利用ルール（案 v0.1）

作成：石川　2026-11-13　コメント期限：2026-11-20（金）

AIのコーディング支援ツールを使うときのルール案です。

1. お客様のコードや資料は、お客様の了承を得た案件だけで使う
2. 個人情報、認証情報、.env は渡さない（除外設定を必ず確認）
3. 生成されたコードもレビューは通常どおり。業務ルールの部分は要件と照らし合わせる
4. PRの説明に、AIツールを使った箇所を一言書く
5. 困ったこと、うまくいったことは月1回共有する

## Q&A

- Q（池田、11/16）：4について、テストだけAIに書かせた場合も書いた方がいいですか。
- A（石川、11/16）：はい、書いてください。レビューする人が「どこを特に見るか」を決めやすくなるので。
