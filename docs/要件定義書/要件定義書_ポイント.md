# 要件定義書（ポイント詳細）

版：v1.0　発行：2026-09-11

## 1. 付与

- 対象：税込の商品代金。送料・ギフト包装料は対象外。
- 率：100円につき1ポイント。100円未満は切り捨て。端数は注文ごとにまとめて判定する（明細ごとではない）。
- 例：3,300円のボトル1点 → 33ポイント。880円の容器2個（1,760円）→ 17ポイント。
- 付与のタイミング：商品の出荷時。同じ注文に2回付与しない。

## 2. 有効期限

- 最後に購入した日から1年間。購入するたびに、保有している全ポイントの期限が延びる。
- 「購入した日」は日本時間の日付で判定する。例：2026年11月18日 0時30分（日本時間）の注文 → 有効期限は2027年11月18日。
- 失効予定日が近い会員には、お知らせメールを送る（バッチ）。

## 3. 利用

- 1ポイント＝1円。購入手続きで全額または一部を充当できる。
- ポイント利用時の消費税の扱いは未決（技術設計書 8章）。
