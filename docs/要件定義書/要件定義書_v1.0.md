# こもれびストア 再構築 要件定義書

版：v1.0　発行：2026-09-11　株式会社みなとデジタル（お客様確認済み）

## 1. 目的

株式会社こもれびリビング様の自社オンラインショップ「こもれびストア」を作り直し、商品ページの見やすさ、ギフト需要への対応、会員ポイントの導入、スマートフォンでの購入手続きの短縮を実現する。本番公開は2027年3月1日（月）。

## 2. 対象範囲

- 対象：商品一覧・詳細、カート、購入手続き、会員、ポイント、ギフト包装・のし、領収書、管理画面、会員データ移行。
- 対象外：Amazonとの在庫連携（営業部様で手作業を継続）、レビュー表示（将来対応）。
- 検討中：予約販売（発売日指定商品）。

## 3. 機能要件

### 3.1 商品

- 商品ページに写真を大きく表示し、色名を出す。保温・保冷の表示を入れる。
- カラーごとに在庫を持つ。

### 3.2 カート・購入手続き

- 購入手続きは3画面（カート確認、お届け先と支払い方法、確認）。
- 確認画面から前の画面に戻っても、入力した内容は残す。

### 3.3 注文・領収書

- 注文確定時に注文確認メールを送る。
- 購入者はマイページから領収書PDFを出せる。宛名を入力できる。
- 領収書はインボイス制度に対応する（税率ごとの対象額と消費税額を記載）。

### 3.4 ポイント

- 税込の商品代金100円につき1ポイントを付与する。送料とギフト包装料は対象外。
- 100円未満の端数にはポイントをつけない。端数は1回の注文の商品代金の合計で判定する。
- 商品の出荷時に付与する。
- 1ポイント＝1円として、購入時に全額または一部を充当できる。
- 有効期限は、最後に購入した日から1年間。詳細は「要件定義書_ポイント.md」。

### 3.5 ギフト包装

- 商品ごとにギフト包装を選べる。包装料は1点につき350円（税込）。
- 出荷指示データに包装の有無を出力し、倉庫（あおば物流様）に連携する。

### 3.6 のし

- 表書きは「無地」「御歳暮」「御年賀」「内祝」「御祝」の5種から選ぶ。名入れは今回の範囲外。
- 出荷指示データに表書きを出力する。

### 3.7 消費税

- 商品価格は税込で表示する。
- 消費税額は、注文ごと・税率ごとに税込合計から計算し、1円未満を切り捨てる。
- 注文画面、注文確認メール、領収書の消費税額は一致させる。
