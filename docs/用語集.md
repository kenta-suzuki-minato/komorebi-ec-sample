# 用語集

お客様（こもれびリビング様）の言葉と、コード上の名前の対応です。

| お客様の言葉 | 意味 | コード上の名前 |
|---|---|---|
| 受注 | 注文を受けること、注文データ | `order` |
| 明細 | 注文の1行（商品、包装料、送料） | `order_lines` / `OrderLine` |
| ギフト包装 | 包装紙で包むサービス。1点350円（税込） | `gift_wrap` |
| のし | 贈り物にかける紙 | `noshi` |
| 表書き | のしに書く言葉。「御歳暮」「御祝」など5種 | `omotegaki` |
| 出荷指示 | 倉庫に送る「何をどう送るか」のデータ | `shipment` |
| 税込 | 消費税を含んだ金額。商品価格はすべて税込 | `inclTax` / `amount` |
| うち消費税 | 税込金額に含まれる消費税額 | `taxTotal` |
| 生成り | 色の名前（白に近いベージュ） | `kinari` |
| 墨 | 色の名前（黒に近いグレー） | `sumi` |
| 桜 | 色の名前（淡いピンク） | `sakura` |
| 若草 | 色の名前（明るい緑） | `wakakusa` |
| 失効 | ポイントの有効期限が切れること | `expire` |
