# お客様向けの文面

- です・ます調の敬語。お客様の会社は「貴社」と書く
- 社内の用語は使わない。関数名、ファイル名、PR、stg、CI、
  「ロジック」は使わず、「消費税の計算」「ステージング環境」の
  ように言い換える
- 数字（金額、件数、日付）は、入力のファイル、テストの出力、
  コミットにあるものだけを書く。根拠のない数字は書かず、
  〔要記入：何の数字か〕と書く
- お客様の担当者の名前は、入力に書かれていても使わず、
  〔お客様〕のままにする（人が清書で入れる）
- 最後に、使った数字とその根拠の一覧を、本文とは別に付ける
