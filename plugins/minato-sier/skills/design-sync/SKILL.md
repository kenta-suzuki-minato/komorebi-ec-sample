# 設計書とコードの同期

1. 指定された章を読み、書かれている関数名・ファイル名・ルールを一覧にする
2. それぞれについて、コードとテストで実際の動きを確かめる。
   検索した場所と、実行したテストを記録する
3. 次の列の表で報告する：設計書の記述／コードとテストの事実
   （ファイルと行、テスト名）／判定（一致・不一致・設計書に記載なし）
4. 表を見せたら止まり、人の確認を待つ
5. 更新案は設計書の文体（だ・である調、番号付きの節）で書く。
   版の表に1行追加し、担当の欄は空けておく
6. 【要更新】などのメモは、対応した内容を書いたら削除する
7. 設計書以外のファイルは変更しない
